開啟相機或任何掃描器，掃描後在瀏覽器開啟，再依下方步驟加入主畫面。

直接開啟

iPhone／iPad（Safari）

請使用 Safari 開啟網址。

  1. 用 Safari 開啟上方連結（掃描 QR Code 或按「直接開啟」）。
  2. 點選「分享」按鈕（iPhone 在畫面底部，iPad 在右上角；若看不到，先點網址列旁或底部的「⋯」）。
  3. 向下捲動選單，點「加入主畫面」。
  4. 確認名稱後點右上角「新增」，主畫面就會出現 QR掃描器。

iOS 版本不同，選單位置可能略有差異；若沒有「加入主畫面」，請確認是用 Safari 開啟，而非應用程式內建瀏覽器。

Android（Chrome）

Samsung Internet 等瀏覽器的選單名稱可能不同。

  1. 用 Chrome 開啟上方連結。
  2. 點右上角選單「⋮」。
  3. 選擇「安裝應用程式」（部分版本為「加到主畫面」，再選「安裝」）。
  4. 在確認視窗按「安裝」，之後可從主畫面或應用程式清單開啟。

若選單裡沒有安裝選項，請先在 QR掃描器 頁面停留幾秒並重新整理一次，Chrome 才會判定為可安裝。

電腦（Chrome／Edge）

Windows、macOS、Linux、ChromeOS 皆適用。

  1. 用 Chrome 或 Edge 開啟上方連結。
  2. 點網址列右側的「安裝」圖示。
  3. 在彈出視窗按「安裝」，QR掃描器 會以獨立視窗開啟，並出現在開始功能表或應用程式清單。

沒看到圖示？也可從瀏覽器選單找「安裝 QR掃描器」或「將此網站安裝為應用程式」。Firefox 桌面版目前不支援安裝網頁 App；macOS Safari 17 以上可用「檔案 → 加入 Dock」。

安裝後可離線使用；有新版本時，App 內會顯示「有新版本可用．立即更新」。掃描全程只在你的裝置上處理，不會上傳影像。
